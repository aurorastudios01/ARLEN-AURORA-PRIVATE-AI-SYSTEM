# ARLEN NEXUS V1 Final Scope

## Vision

ARLEN NEXUS V1 will focus on stability, performance and a complete AI workstation experience.

Target:
- Offline-first AI assistant
- 4GB RAM optimized Windows application
- Reliable daily-use workstation

---

# Core AI System

Included:

- Ollama integration
- Qwen2.5:3B local model support
- Offline chat
- Context understanding
- Basic local memory
- User preferences

---

# System Assistant

Included:

- CPU monitoring
- RAM monitoring
- Storage monitoring
- Battery status
- Brightness control
- Sound control
- System information
- ARLEN cache cleanup
- RAM/system refresh utilities

Not included:

- Full PC takeover
- Mouse automation
- Keyboard automation
- Background monitoring

---

- Available tools
