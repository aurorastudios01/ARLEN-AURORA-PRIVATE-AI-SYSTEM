# ARLEN NEXUS - Next Update Planner

## Project Vision
ARLEN NEXUS is a private offline-first AI workstation for Windows. It is designed as an AI agent, not only a chatbot.

Core concept:
- Ollama = AI Brain
- Python Tools = AI Hands
- Local Storage = Personal Memory
- Premium UI = AI Workstation Experience

# Current Completed Setup

## Environment
- Python 3.11.9 installed
- Ollama 0.32.15 installed and working
- Qwen2.5:3B model installed and tested
- FFmpeg installed

## Image Processing Base Installed
- Pillow
- OpenCV
- NumPy
- piexif
- rembg (optional background module)

## Current Hardware Target
- Optimized for 4GB RAM class PC
- Low resource architecture
- No heavy background services

---

# Current Design Decisions

## Voice System
- No AI voice assistant
- No Whisper/TTS in main application
- Only UI sounds:
  - Startup sound
  - Close sound
  - Warning sound
  - Processing sound
  - File/PDF/Image completion sounds

## Dynamic Interface
- Animated backgrounds
- Multiple animated AI spheres
- Theme system
- Command Center
- System status panels

Users cannot directly add random files from File Manager. Themes, spheres, backgrounds and sounds will be managed from inside ARLEN NEXUS only.
