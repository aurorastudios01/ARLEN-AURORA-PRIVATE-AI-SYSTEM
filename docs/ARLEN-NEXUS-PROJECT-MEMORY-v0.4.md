## Non-negotiable product contract

ARLEN NEXUS is a premium offline-first Windows desktop assistant. End users must receive a portable folder with `ARLEN NEXUS.exe` and its runtime; they must not install an editor, Python, Visual Studio, Node, Rust, Ollama or developer dependencies. Public search uses Brave under owner policy. Personal uploads, login/actions, messages, purchases, destructive operations and protected changes require approval. Local images are never automatically blocked, blurred, deleted or uploaded. Personal data remains under `%LOCALAPPDATA%/ARLEN NEXUS/UserData` and must survive application updates.

The UI remains cinematic and serious, uses dedicated feature pages, supports Obsidian/Crimson/Emerald/Violet/Arctic themes, owner visuals, neural-sphere states and the `Ctrl+Alt+A` Windows shortcut target.
